What might happen next?

How reliable was the estimate?

These scores compare the model with readings it did not train on. Lower MAE and RMSE usually mean smaller errors.

Before connecting

Set API keys in your server environment and restart EcoWatt. A key alone will not display Connected; that status requires a successful authenticated provider response.

GNANI_PRISMA_API_KEY · GNANI_EVON_API_KEY · GNANI_TIMBRE_API_KEY
Prisma STT and Timbre TTS follow Gnani’s documented API contracts. Evon’s public endpoint and payload contract have not been verified, so EcoWatt does not send guessed requests or label Evon connected.
